### §B-0. 폐기 사유 — v1 은 노이즈를 읽는다

top_n=**3** 등비중/sp100 의 **12주 초과수익 σ = 7.5%p**(2026-08-01 실측, 캐시 패널·무작위 3종목).
연환산 트래킹에러 TE = 7.5/√(12/52) = **15.6%p**. (이 절의 v1 결함 분석은 등록 당시 파라미터인
top_n=3 기준이다. v2.1 운용 파라미터 σ 는 §B-0b.)

**알파가 정확히 0인 전략**에 v1 규칙(초과 ≥0 계속 / < −5%p 중단)을 적용하면:

| | 12주 1회 판정 | 20주까지 누적(4주 연장 2회) |
|---|---|---|
| 계속 | **50%** (실측 48%) | **60%** |
| 중단 | 25% (실측 24%) | 35% |
| 연장 | 25% | 4% |

**알파 0 전략이 소액 실거래 게이트를 통과할 확률 60%.** 판정선 "초과 ≥ 0"은 동전던지기다.

원인은 검정력이다. t = IR<sub>연</sub> × √(관측연수) 이므로 12주(0.231년)에 t ≥ 1.645 를 만들려면
IR 3.4 = **연 알파 +53%p** 가 필요하다. 뒤집으면 **12주가 80% 검정력으로 잡을 수 있는 최소
알파 = 연 +81%p**(12주 초과 +18.6%p). 그 아래는 전부 노이즈에 묻힌다. IR 0.5(연 +7.7%p)를
80% 검정력으로 잡으려면 **약 25년**이 걸린다 — 규칙 설계로는 고칠 수 없는 물리적 한계다.

**따라서 v2 의 방침: 성과 유의성을 "계속"의 조건으로 쓰지 않는다.** §B 가 실제로 걸러낼 수
있는 것은 (i) 운영 결함과 (ii) 대형 손실뿐이고 그 둘만 차단 게이트로 삼는다. 성과 통계량은
**"중단" 쪽 단측 스크린**으로만 쓰며, 나머지는 **판정 불가**로 명시한다.

### §B-5. 성과 통계량 [v2 신규 — 위험조정·유의수준 기반]

**표본** = 창 내 **연속 ok-런 쌍의 일별 초과수익**

```
d_i = (NAV_i / NAV_{i-1} − 1) − (SPY_i / SPY_{i-1} − 1)
```

- 첫 쌍의 기준선은 기존 `paper_nav.metrics` 규약 그대로(NAV = seed $100k, SPY = 첫 집계 세션
  직전 종가). 즉 지표 산출 기준이 A6 과 갈라지지 않는다.
- SPY 종가는 **세션 일자로 조회** — 결번으로 세션이 건너뛰면 양쪽 다 같은 구간을 건너뛰므로
  구간 정합이 자동으로 유지된다.
- n = 쌍 개수 ≈ 12주 60 · 16주 80 · 20주 100.

**통계량**

```
t       = mean(d) / (stdev(d) / √n)                # 단측 검정용, 판정선
IR_ann  = mean(d) / stdev(d) × √252                # = t / √(관측연수). 보고용, 판정선 없음
```

**HAC(Newey-West) 미적용 — 사전등록.** 일별 d 의 자기상관은 <0.1 로 예상된다(보유는 지속되지만
수익률 혁신은 근사 iid, 미국 대형주라 비동기가격 없음) → SE 보정폭 <5% 로 판정선을 움직이지
못한다. 대신 판정문에 lag-1 자기상관 ρ₁ 을 **보고**한다. |ρ₁| > 0.2 여도 **규칙은 바꾸지 않고**
그 사실만 판정문에 명시한다(사후 변경 = 룩어헤드, §B-9).

**코드 확장 前 중간점검용 교차선**(계산 불필요, `paper_nav` 현행 출력만으로): 누적 초과수익
밴드 **±1.30σ**, σ = **5.8%p**(top_n=5, §B-0b) × √(주/12) → **12주 ±7.6%p · 16주 ±8.7%p ·
20주 ±9.8%p**. [v2.1 갱신 — top_n=3 기준 구값은 ±9.8/±11.3/±12.6%p 였다.]
t 와 밴드가 어긋나면 **실현 TE ≠ 5.8%p 라는 정보**이며(§B-0b 의 vol_target 단서 참조), 판정은
**항상 t 우선**(실현 데이터로 자기교정하므로).

### §B-6. 판정 — 3단 [v2 확정]

경계 상수 **|t| ≥ 1.30** = 단측 10%. (n=60 에서 t₀.₁₀=1.296, n=100 에서 1.290 — 창 전체에서
같은 상수를 써도 오차 1% 미만이라 look 마다 임계값을 다시 계산하지 않는다.)

| 판정 | 조건 |
|---|---|
| **중단/재설계** | 게이트 A 또는 B 위반 **또는** `t ≤ −1.30` |
| **계속** (L1 진입 자격, `capital-gate-ladder.md`) | 게이트 A·B 통과 **AND** `t ≥ +1.30` |
| **판정 불가(표본 부족)** | 게이트 A·B 통과 AND `−1.30 < t < +1.30` → **연장** |

- "계속" 판정문에는 **"유의성 주장 아님 — 단측 10%, 다중 look 보정 없음"** 을 병기한다.
- **연장 = +4주씩 최대 2회** (1차 12주 · 2차 16주 · **최종 20주**). 연장 기간에도 실험은
  무개입 그대로 가동한다. 연장의 실질 이득은 성과 검정력(12→20주 t 는 1.29배뿐)이 아니라
  **게이트 A 표본 축적**(60런 → 100런)에 있다.
- **최종 look(20주)에서도 판정 불가 → "조건부 계속 = L1 진입"** (게이트 A·B 통과 전제).
  근거 셋: (i) §B-0 대로 성과 유의성은 원리적으로 도달 불가이므로 그것을 진입 조건으로 두면
  사다리가 **영구히 멈춘다** — 본 문서 원칙 2("환경이 부족해서"가 판정 회피의 영구 사유가 되는
  것을 차단)와 **같은 논리가 검정력 부족에도 적용된다**. (ii) L1 이 측정하려는 것(실주문 경로·
  슬리피지·개입 충동)은 paper 에서 **원리적으로 측정 불가** — 진행이 유일한 학습 경로다.
  (iii) 위험 통제는 유의성이 아니라 **자본 상한**이 한다(L1 진입은 준비 단·자본 0, 실 상한은 L2 $200 수동).
  판정문에 **"성과 판정 불가 상태에서의 진행 — 엣지 근거 아님"** 을 반드시 적는다.
- **레짐 필터 주의(판정문 필수 병기)**: 창 안에서 SPY<200MA 로 목표비중 전량 0(전량 현금)인
  세션이 **10회 이상**이면 그 구간의 d 는 종목선정이 아니라 **레짐 타이밍**을 측정한 것이다.
  현금 세션 수를 판정문에 명시하고 해석에 반영한다. **규칙은 바꾸지 않는다.**

### §B-7. 새 규칙의 오판율

몬테카를로 20만 경로. 일별 d ~ N(μ, σ/√60), look = 60/80/100 세션, 첫 교차가 판정 확정.
"판정 불가"는 최종 20주 look 까지 무교차 = 조건부 계속으로 귀결.
**재현**: `python research/paper_b_decision_power.py` (자가검증 `--selftest`, 고정 시드).
사전등록 문서의 숫자는 재현 가능해야 하므로 이 표는 그 스크립트 출력의 전사다.

| 진짜 알파 | 규칙 | 계속 | 중단 | 판정 불가 |
|---|---|---|---|---|
| **0** (IR 0) | v1 | **60%** | 35% | 4% |
| | **v2/v2.1** | **16%** | 16% | 68% |
| **IR +0.5** (좋은 전략) | v1 | 71% | **26%** ← 오살 | 4% |
| | **v2/v2.1** | 24% | **10%** ← 오살 | 66% |
| **IR −0.5** (나쁜 전략) | v1 | 50% | 46% ← 포착 | 4% |
| | **v2/v2.1** | 10% | 24% ← 포착 | 66% |

**[v2.1] top_n 3→5 는 이 표를 바꾸지 않는다 — 의도된 성질이다.** t 는 실현 σ 로 자기정규화되므로
v2 판정선의 오판율은 **σ 에 불변**이다(실측: σ 7.5%p → 16.0/16.0/68.1%, σ 5.8%p →
16.0/16.0/67.9%). 바뀌는 것은 **같은 오판율이 적용되는 알파 수준**이다 — 위 표의 IR ±0.5 가
top3 에서는 연 ±7.8%p, top5 에서는 **연 ±6.0%p**. 즉 **더 작은 알파도 같은 확률로 잡는다**
= 검정력 이득의 정확한 정의다. (대조: v1 의 −5%p 는 절대선이라 σ 에 의존한다 — σ 축소만으로
중단률이 35.3% → 30.4% 로 흔들린다. 사전등록 규칙이 파라미터 변경에 취약하다는 v1 의 또 다른 결함.)

읽는 법:
1. **알파 0 을 "계속"으로 오판: 60% → 16%** (12주 1회 기준으로는 50% → 9.9%). 이번 재설계의 목적.
2. **좋은 전략을 "중단"으로 오살: 26% → 10%.**
3. 나쁜 전략 포착률은 **46% → 24% 로 내려간다** — v2 가 지불하는 대가이며 숨기지 않는다.
   다만 v1 의 46% 는 대부분 노이즈로 산 것이다: **판별력**(나쁜 전략 중단률 − 알파0 중단률)은
   v1 **+11%p** vs v2 **+8%p** 로 사실상 같다. 두 규칙은 같은 통계량의 단조변환이라 **정보량이
   같고, v1 은 정보가 없는 곳에서 단정할 뿐이다.** 나쁜 전략에 대한 실제 방어선은 성과 판정이
   아니라 **게이트 B(MDD 20%) + L2 자본 상한 $200**(L1 은 준비 단·자본 0) 이다.
4. 다중 look 보정은 하지 않았다(사전등록). 단측 10% × 3 look 이 누적 16% 가 되는 것이 위 표에
   이미 반영돼 있으며, 그 값을 그대로 공시하는 것으로 갈음한다.

### 부록 — `tools/paper_nav.py` 확장 스펙 (§B-5 산출용, 코드부대 작업)

1. `load_paper_navs` 결과의 연속 세션쌍마다 `d = (NAV_i/NAV_{i-1} − 1) − (SPY_i/SPY_{i-1} − 1)`;
   첫 쌍은 `(base, spy_base)` 사용(기존 `metrics` 기준선 규약과 동일). SPY 종가는 **세션 일자 키**로
   조회하고, 종가 결측 세션은 쌍 자체를 스킵(양쪽 동시).
2. `tstat(d)` → `(t, ir_ann)`: `n < 40` 또는 `stdev == 0` 이면 `None`;
   `t = mean/(stdev/√n)`, `ir_ann = mean/stdev×√252`. **stdlib `statistics` 만** 사용(신규 의존 0).
3. 출력 1줄 + JSON 키 추가: `n_pairs` · `t` · `ir_ann` · `rho1`(lag-1 자기상관, 보고용) ·
   `cash_sessions`(런 레코드의 `weights` 합 = 0 인 런 수 — §B-6 레짐 주의 트리거).
4. `selftest()` 에 assert 3개: 알려진 d 시계열의 t 손계산 대조 · 상수 시계열 `stdev=0 → None` ·
   `n<40 → None`. 기존 `metrics` 산출값은 **불변**이어야 한다(회귀 방지 assert 유지).
5. 확장 전까지는 §B-5 의 **고정밴드 교차선**(±1.30σ)으로 중간점검한다 — 판정 자체는 t 확보 후.
