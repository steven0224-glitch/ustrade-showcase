- **2026-07-22 · 분산비율(DR) 관찰 지표 — 테마 중복베팅 계측**: DR = Σwᵢσᵢ / σ_p. 하우스 공인
  구멍 직격 — 섹터·테마 한도가 코드에 없어 risk 데스크 사람 눈이 유일 방어선(HOUSE.md §3).
  선정 결과의 DR 을 selection_review·대시보드에 관찰 전용 병기 → DR≈1 이면 "티커만 다른
  한 베팅" 경보. top_n 5~10 소표본이라 sample cov 로 충분(N≪T), LW shrinkage 는 옵션.
  관찰 전용이라 실험 비오염 명백 → 원칙 1 단서로 사용자 승인 시 pre-판정 구현 가능.
  출처: x.com/RuujSs/article/2077040860735349183 ch.1 (07-14).
