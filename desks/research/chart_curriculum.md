# 차트 강의 커리큘럼 대장 (chartist 원자료)

> 사용자가 노션 캡처로 전달한 차트분석 강의의 전수 대장. chartist 페르소나(및 후속 재설계)의
> **원자료 출처**다. 새 강의가 오면 이 파일에 append 하고 상태 태그를 붙인다.
> 최초 확정 2026-08-28. 시즌2는 **성장 중**(사용자: "앞으로 업데이트 될 것").

## 상태 태그 — 5종 (혼동 금지)

| 태그 | 뜻 | 재검사 조건 |
|---|---|---|
| ✅ **이식** | 코드에 반영됨 | — |
| ⚠️ **부분/프록시** | 일부만·근사로 이식 | 원 강의대로 완성 여지 |
| 🟢 **순수 미이식** | 검토·백테스트 이력 **전무** | 자료로 **첫 검사** — 완전 열림 |
| 🟡 **데이터게이트** | 성적 아님, **실시간 거래량 부재**로 막힘 | 자료 무관 — **KIS 볼륨 섀도 라이브 + 검증**이 조건 |
| 🔴 **성적 기각** | 백테스트 돌려서 **패배**(기록 있음) | 같은 자료 반복 무효 — **원 기각을 이기는 새 각도** 필요 |
| ⚪ **비대상/보류** | 코드화 대상 아님(심리) 또는 저우선 | — |

⚠️ **"미이식 ≠ 기각".** 🟢은 결정이 아니라 미검토다. 🔴만 근거 있는 결정이다.

## 종합 — 뭐가 실행 가능한가

**핵심 통찰: 시즌2의 진짜 net-new는 진입신호가 아니라 chartist를 살리는 구조 3종이다.**
1. **ATR 사이징(7주차)** — `min_risk_frac` 진입 0 버그 직접 수리. 리스크 작으면 거부가 아니라 증량.
2. **ADX(9주차)** — 횡보장 whipsaw 차단.
3. **RS(2주차)** — 고정 watchlist 노화 대안.

이 3종은 **신호 오버레이가 아니라 구조**라 TA 오버레이 나쁜 prior(5기각/0통과: 매물대·VWAP·다이버전스6·볼륨확인, [memory.md:48])에 안 걸린다.

**지금 열려 있는 것(🟢 순수 미이식, 자료 확보됨):** 8편 차트패턴 · 13/S2-3 MACD · 14/S2-4 볼린저 · 15/6월특별편 ICT. → 오프라인 백테스트 대상.
**부분 해제(🟡→②):** 매물대·VWAP = KIS 볼륨 섀도 **라이브 확인됨**(2026-08-28 VM 실측, systemprofile 경로에 ~21MB). ①섀도수집 충족 → ②오프라인검증 착수 가능. 단 회전 정책(20MB 단일 백업, 오래된 것 소실)이라 장기 코퍼스는 주기 수확 필요. 피보나치·RS·ADX = §A 판정 후 백테스트.
**닫힌 것(🔴):** 다이버전스(6변형 패배). 새 각도(예: Fib+매물대 결합) 없으면 불가.

## 갱신 규약

- 새 강의 캡처 오면 이 표에 행 추가 + 상태 태그.
- 상태 변경(예: 백테스트 통과)은 태그 갱신 + `desk_memory.py append research` 로 사유 기록.
- ⚠️ §A 동결 중 — 이 대장은 **카탈로그일 뿐 코드 반영 지시가 아니다**. 착수는 §B 판정 후 큐(`docs/queue-post-freeze.md`) 경유.
